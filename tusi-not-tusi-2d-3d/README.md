# Tusi and Not-Tusi Illusions in 2D and 3D

Interactive demonstrations and mathematical tools accompanying *The Tusi and Not-Tusi Illusions: A Tool for Studying Emergence in Two and Three Dimensions* by Arthur G. Shapiro and Christophe Hurter.

The revised paper presents a mathematical stimulus-generation framework and an interactive research platform. It examines how phase relationships organize simple local motions into global forms, finite-sampling aliasing, changes in motion law and circle geometry, and spatial constructions using indexed rotations, a carrier ring, and a seed direction. It reports no perceptual experiment. Perceptual validation and proposed applications in visualization, art, human–machine comparisons, and virtual or augmented reality remain future work.

The software also includes exploratory extensions beyond the revised paper. In particular, parameter-space and point-space interpolation are available as software demonstrations; the paper does not develop or compare these methods or establish perceptual continuity between configurations. The six public experiments use browser graphics rather than an immersive application.

## Run locally

Use Node.js 22 or later:

```sh
npm run serve
```

Alternatively, with Python 3:

```sh
python -m http.server 8000
```

Open http://127.0.0.1:8000/ . Serve the files over HTTP; opening an HTML file directly with a `file:` URL does not reliably load JavaScript modules. No package installation or frontend build is needed for the demonstrations. Three.js is included locally, and the public demonstrations require no CDN or runtime network service.

## Interactive demonstrations

| Demonstration | Focus |
| --- | --- |
| [Tusi, Motion Control](examples/pedagogy/v0/) | Harmonic and constant-speed motion on fixed straight paths. |
| [Tusi, Phase Control](examples/pedagogy/tusi2/) | Phase winding, amplitude, and signed displacement on fixed straight paths. |
| [Not Tusi](examples/pedagogy/v0bis/) | Global forms generated by motion on fixed circles. |
| [Parameter Sets](examples/pedagogy/v3/) | Preset exploration and parameter/point interpolation, an extension beyond the paper. |
| [3D Tusi](examples/pedagogy/tusi3d/) | Fixed straight paths with separate geometry and motion controls; additional geometry families extend the paper. |
| [3D Not Tusi](examples/pedagogy/v4/) | Carrier-ring construction, indexed rotations, seed direction, and single-axis or multi-axis animation. |

The standalone [2D Tusi](examples/tusi-2d/), [2D Not-Tusi](examples/not-tusi-2d/), [3D Tusi](examples/tusi-3d/), [3D Not-Tusi](examples/not-tusi-3d/), and [interpolation](examples/interpolation/) pages expose the reusable model API. The standalone Fibonacci-sphere Not-Tusi model is a retained software extension, distinct from the carrier-ring construction in the revised paper and the public 3D Not Tusi demonstration.

## Tests

```sh
npm test
npm run test:browser
```

The browser smoke tests require a local Chrome or Edge executable. Set `BROWSER_BIN` if it is installed outside a standard location. Numerical and structural tests cover paths, phase relationships, sampling, serialization, interpolation constraints, release files, and the local server. Browser smoke tests exercise the six public routes and launcher. Tests do not constitute perceptual validation.

## Build a smaller web distribution

```sh
npm run build:publication
```

This generates `dist/tusi-not-tusi-six-experiences/` containing the six public demonstrations and their runtime dependencies. It omits source documentation, standalone author examples, and tests. `dist/`, `output/`, and temporary files are excluded from version control. The repository root itself is also a static website with `index.html` as its entry point; upload the contents of this folder to the repository root.
